# Człowiek • Bóg • AI

## Filozofia człowieka, duchowości i przyszłości inteligencji

**Projekt Sylwestra Markuszewskiego**

„Człowiek • Bóg • AI” jest otwartą biblioteką ukończonych książek filozoficznych i duchowych poświęconych pytaniom o człowieka, Boga, dobro, mądrość, wolność, odpowiedzialność, sens oraz przyszłość relacji między człowiekiem i sztuczną inteligencją.

Projekt wyrasta z przekonania, że rozwój inteligencji — ludzkiej lub sztucznej — nie powinien być oddzielony od pytań o to, **jak korzystać z wiedzy i możliwości w sposób odpowiedzialny i dobry**.

Nie jest to projekt techniczny ani próba stworzenia zamkniętego systemu filozoficznego. Nie przedstawia własnych tekstów jako objawienia ani bezpośredniego słowa Boga. Są to ludzkie rozważania nad Bogiem, prawdą, dobrem i przyszłością, rozwijane również przy wsparciu sztucznej inteligencji jako narzędzia pracy intelektualnej i redakcyjnej.

## Zasada publikacji

Do tego repozytorium trafiają **wyłącznie ukończone książki lub oficjalne odnośniki do ich publikacji**. Wersje robocze, szkice i dyskusje powstają poza publiczną biblioteką.

Wszystkie książki tworzone w ramach projektu mają być dostępne **bezpłatnie do czytania**.

Bezpłatny dostęp nie oznacza rezygnacji z praw autorskich. O ile przy danej publikacji nie zaznaczono inaczej, obowiązuje zasada **Wszelkie prawa zastrzeżone / All rights reserved**.
